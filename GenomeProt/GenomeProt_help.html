GenomeProt Help Guide

Overview

GenomeProt is a comprehensive proteogenomic analysis tool used to identify:

  • Canonical proteins

  • Noncanonical proteins (uORFs, dORFs, noncoding RNA–derived proteins)

  • Variant peptides and proteoforms

The workflow consists of four steps:

    Database Generation

    Analyse MS Proteomics (External Step)

    Integrate Data

    Visualise Results

1. Database Generation

Users can choose between short-read and long-read options depending on their data type.

The Shiny web server supports:

    Pre-aligned BAM files. The test dataset file can be downloaded here.

    Transcript annotations provided as a GTF file

By default, the app loads a demo dataset (BAM file input) to demonstrate processing and output files.

Generate Database Using Demo Dataset

Steps:

    Navigate to the Generate Database tab.

    Click Submit using default options.

    The app processes the BAM file.

Output Files:

    proteome_database.fasta : Multi-FASTA protein database

    proteome_database_metadata.txt : TSV file containing annotations for candidate protein sequences

    proteome_database_transcripts.gtf : GTF file with transcript coordinates used to generate the proteome database

The test results file can be downloaded here.

Important Notes

    Results from this step can be downloaded within the app.

    To generate a database directly from FASTQ files, or BAM files larger than 30 GB, use the command-line version.

    Command-line instructions are available here.

2. Analyse MS Proteomics (External Step)

Using the database (.fasta) generated in Step 1:

    Analyse proteomics data using your preferred search algorithm.

    Identify proteins and peptides from your dataset.

This step is performed outside the Shiny application.

3. Integrate Data

This step maps peptides identified in Step 2 to spliced transcript coordinates.

Required Files

From Step 2:

    peptide_data.tsv (must follow required format)

From Step 1:

    proteome_database_metadata.txt

    proteome_database_transcripts.gtf

Steps to Map Peptides

    Download ZIP file containing:

      proteome_database_metadata.txt

      proteome_database_transcripts.gtf

    Extract ZIP file

    Download demo peptide_data.tsv from here

    Navigate to Integrate Data tab

    Upload required files

    Click Submit

After successful mapping:

    The Download results (zip) button turns green.

    Click to download output zip file.

Output Directory Contents

    summary_report.html : Summary report of mapped peptides, transcripts, and ORFs

    report_images/ : Folder containing PDF versions of graphs from the summary report

    peptide_info.tsv : Detailed peptide mapping annotations

    combined_annotations.gtf : GTF file with mapped peptides and transcript coordinates

    peptides.bed12 : BED12 file with mapped peptide coordinates for UCSC Genome Browser visualisation

    transcripts.bed12 : BED12 file with transcripts supported by peptide evidence for UCSC Genome Browser visualisation

    ORFs.bed12 : BED12 file with ORFs supported by peptide evidence for UCSC Genome Browser visualisation

4. Visualise Results

This step visualises peptides on transcript and gene coordinates using IsoVis.

Step 1: Upload Data

Click Upload Data and upload:

    combined_annotations.gtf : (Stack Data File: .gff/.gtf/.bed; max 3GB)

Optional:

    Heatmap data file (raw transcript counts)

    Peptide Counts Data File (for peptide intensities)

Step 2: Apply Filters

    Click Apply

    Select gene of interest

    Use filters

When selecting ORFs with UMPs Genes with shared peptides (no unique peptides) can be excluded.

Step 3: Gene Selection

    Enter Gene Name or ENSEMBL ID

    Press Enter

Visualisation Output

The visualisation includes:

    Separate tracks for peptides and transcripts

    Coding regions shown as thick dark gray boxes

    Uniquely mapped peptides (orange)

    Peptides shared across ORFs (dark blue)

    Peptides shared across genes (dark gray)
